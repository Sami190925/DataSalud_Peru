
# Modelo documental - DataSalud_NoSQL

## 1. Descripción

Se utilizó MongoDB para almacenar y administrar información relacionada con los establecimientos de salud y los casos de neumonía en Piura.

MongoDB es una base de datos NoSQL que organiza la información mediante documentos y colecciones, permitiendo trabajar con datos de manera flexible.

## 2. Base de datos

Nombre: DataSalud_NoSQL

## 3. Colecciones

La base de datos contiene dos colecciones:

- renipress: almacena información relacionada con los establecimientos de salud.
- neumonia_piura: almacena los registros relacionados con los casos de neumonía en Piura.

## 4. Organización de los datos

Los datos se almacenan mediante documentos BSON, que tienen una estructura similar a JSON.

Cada documento contiene diferentes campos según la información importada desde los archivos originales.

## 5. Herramienta utilizada

Se utilizó MongoDB Compass para:
- Visualizar la base de datos.
- Revisar las colecciones.
- Consultar los documentos.
- Aplicar filtros.
- Realizar operaciones de agregación.

## 6. Conclusión

El uso de MongoDB permitió trabajar con una alternativa NoSQL para almacenar y consultar la información del proyecto DataSalud Perú.
